# 🚢 Task 1 - Titanic Survival Prediction

This is my first task for the **CODSOFT Machine Learning Internship**.  
It predicts whether a Titanic passenger survived or not using a Random Forest model and Streamlit web app.

---

## ⚙️ Features
- Data cleaning and preprocessing  
- Feature engineering (`FamilySize`, `IsAlone`, `AgeGroup`)  
- Random Forest Classifier model  
- Interactive Streamlit app for predictions  

---

## 🧩 Files
| File | Description |
|------|--------------|
| `train_model.py` | Trains the ML model and saves it as a `.pkl` file |
| `app.py` | Streamlit app for live predictions |
| `Titanic-Dataset.csv` | Dataset used for training |
| `titanic_model_advanced.pkl` | Trained Random Forest model |
| `titanic_scaler.pkl` | Scaler used for feature normalization |
| `requirements.txt` | Required Python libraries |
