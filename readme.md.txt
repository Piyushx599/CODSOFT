# Credit Card Fraud Detection 🧾

This project analyzes credit card transactions to detect fraudulent activity using Machine Learning.

## 📊 Dataset
The dataset used: `creditcard.csv`  
It contains anonymized transaction features and a target column `Class`:
- `0` → Legitimate transaction  
- `1` → Fraudulent transaction  

## 🧠 Model Workflow
1. Data preprocessing  
2. Balancing dataset (sampling)  
3. Splitting into train/test sets  
4. Scaling features  
5. Model training & evaluation  

## 🧰 Technologies
- Python  
- pandas, numpy  
- scikit-learn  
- Jupyter Notebook  

## 📈 Results
Accuracy, Precision, Recall, and F1-score metrics are used to evaluate the model.
