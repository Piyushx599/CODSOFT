## 🧩 Task 1 – Titanic Survival Prediction
**Goal:** Predict whether a passenger survived the Titanic disaster using machine learning.  
**Highlights:**
- Performed EDA and data cleaning on the Titanic dataset  
- Applied Logistic Regression and Decision Tree models  
- Evaluated accuracy and visualized feature importance  
**Tech Used:** Python, Pandas, Scikit-learn, Matplotlib  
📁 [View Task 1 Folder](./Task1_Titanic_Survival_Prediction)

## 🎬 Task 2 – Movie Rating Prediction
**Goal:** Predict IMDb ratings for Indian movies based on features such as genre, duration, director, and votes.  
**Highlights:**
- Data preprocessing and feature engineering (`Main_Genre`, `Is_MultiGenre`, `Log_Votes`, etc.)  
- Trained multiple models (Linear Regression, Random Forest, Gradient Boosting, XGBoost)  
- Achieved **R² ≈ 0.87** using XGBoost  
- Deployed via **Streamlit** web app  
**Tech Used:** Python, Pandas, Scikit-learn, XGBoost, Streamlit  
📁 [View Task 2 Folder](./Task2_Movie_Rating_Prediction)

---

## 💳 Task 3 – Credit Card Fraud Detection
**Goal:** Identify fraudulent credit-card transactions using classification models on highly imbalanced data.  
**Highlights:**
- Conducted **EDA** to analyze transaction patterns and class imbalance  
- Implemented **data preprocessing** with scaling and **SMOTE** oversampling  
- Compared models: Logistic Regression, Random Forest, XGBoost, and Isolation Forest  
- Optimized thresholds for higher **recall** on fraudulent transactions  
- Achieved **ROC-AUC ≈ 0.96** (best model: XGBoost)  
**Tech Used:** Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn  
📁 [View Task 3 Folder](./Task3_CreditCard_Fraud_Detection)
