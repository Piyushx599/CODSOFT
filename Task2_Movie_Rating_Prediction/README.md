**# 🎬 Task 2 — Movie Rating Prediction**



**This project predicts \*\*IMDb movie ratings\*\* for Indian films using various features such as genre, duration, votes, director, and actors.**  

**It demonstrates an end-to-end \*\*Data Science and Machine Learning pipeline\*\* — from data cleaning and feature engineering to model training and Streamlit deployment.**



**---**



**## 📌 Project Overview**



**- \*\*Objective:\*\* Predict IMDb movie ratings based on metadata.**  

**- \*\*Dataset:\*\* IMDb Movies India dataset**  

**- \*\*ML Models:\*\* Linear Regression, Random Forest, Gradient Boosting, XGBoost**  

**- \*\*Best Model:\*\* XGBoost Regressor**  

**- \*\*Evaluation Metric:\*\* R² Score ≈ \*\*0.87\*\***  

**- \*\*Deployment:\*\* Streamlit web app for real-time prediction**  



**---**



**## 🧠 Key Features**



**- Extensive data cleaning and preprocessing**  

**- Feature engineering:**  

  **- `Main\_Genre`, `Is\_MultiGenre`, `Num\_Actors\_Known`, `Log\_Votes`**  

**- Model comparison and performance visualization**  

**- Saved model and preprocessing pipeline using `joblib`**  

**- Interactive \*\*Streamlit\*\* app for live predictions**  



**---**



**## 🧩 Project Workflow**



**1. Load and explore the dataset**  

**2. Handle missing values and clean text data**  

**3. Encode categorical features**  

**4. Feature scaling**  

**5. Train \& compare multiple regression models**  

**6. Evaluate results (MAE, RMSE, R²)**  

**7. Save the best model and deployment assets**  

**8. Build and deploy a Streamlit app**
